# Miki Writer

*[English](README_EN.md)*

**把一个已经想清楚的选题，直接变成能发出去的稿子——小红书、朋友圈、公众号、口播稿/视频脚本、GitHub README，一条流程走完。**

## 能做什么

- **动笔前先自己找材料，不等你喂**：会去你的 Obsidian Vault 里翻已经整理好的每日记录，找和这个选题相关的内容，看看你当时是怎么想、怎么说的。
- **五类事实分开处理**：仓库可验证的事实、你自己说过的话、第三方反馈、AI 的推断、会过时的数据分开标注，不把一句话包装成板上钉钉的结论，也不编不存在的细节。
- **材料不够就主动问**：找不到相关记录、或记录撑不起一篇完整表达时，先问会改变主线的问题，问完再写，不硬凑。
- **不套固定模板**：每篇现场识别一条主导推进线（事情怎么变化的、认知怎么变化的、怎么取舍的），结构从具体事实里长出来。
- **保留你的声音**：自然口语、自嘲、真实情绪都留着，不自动统一润色成一种"高级感"腔调。
- **去 AI 味两阶段校准**：先列出哪里像 AI 写的，再从最深层的地方开始改，不是机械地把关键词反着写。
- **终稿保护**：说"这是终稿"之后只提建议、不再动正文；被删掉或否决的内容不会悄悄再加回来。
- **轻量文风自进化**：每次手改完一篇稿子，会对比改动前后的差异更新一份文风记忆，只从真实改动里学，不学原样保留的句子。
- **多格式交付**：小红书/抖音图文、朋友圈文案、公众号长文、口播稿/视频脚本/提词器稿、技术长文、GitHub README（中英双语），各自有对应的格式规范和合规自查。
- **技术长文一键多平台分发**：写完一篇技术长文/项目故事的主稿后，可以按各平台规范改写适配到公众号和小红书，事实和结论保持一致，只调整表达方式和篇幅。素材不局限于代码仓库，也包括实验数据、链接里的评论反馈、你自己的口述说明。
- **配图建议（只出文字建议，不生成图片）**：小红书图文、朋友圈文案、技术长文这几类会附带配图思路——AI 生图提示词、该截哪张图、或者信息图该包含哪几块内容，图片本身需要你自己生成或截取。
- **小说（虚构创作）**：帮你把一个还没落地的想法梳理成前提、世界观、人物，再定大纲、逐章推进。这是唯一不受"事实边界"约束的模式——情节和人物本来就可以虚构。
- **交互式网页（HTML）**：技术长文的网页版、README 里的可运行演示、独立介绍页，产出单个自包含的 `.html` 文件（可以有真正的点击展开、tab 切换、图表交互），不依赖构建工具，双击就能打开；不自动部署上线。

## 必须配合 Obsidian 使用

这个 Skill 是围绕 Obsidian 设计的：写作前主动去你的 Obsidian Vault 里找素材，是它最核心的一步。目前**没有**做其他笔记软件的通用适配——如果你想接到别的工具上，需要自己改写 `SKILL.md` 里读取素材那部分逻辑，不是开箱即用。如果你还没用 Obsidian，看下面的安装步骤。

## 快速开始（不熟悉 AI 工具也能跟着做）

### 第一步：装 Obsidian

1. 打开 [obsidian.md](https://obsidian.md)，根据你的系统（Windows / Mac / Linux / 手机）下载安装。
2. 安装完成后打开，创建一个新的 Vault（可以理解成一个专门用来存笔记的文件夹）。
3. 界面按钮名称可能随版本更新有变化，具体操作以 Obsidian 官方安装说明为准。

### 第二步：把这个 Skill 接到你的 AI 工具上

- **Claude**（网页版 / 桌面版）：在设置里找 Skills / Capabilities 相关入口，按当前版本的引导添加这个文件夹。
- **Claude Code**：把这个文件夹放进项目的 `.claude/skills/` 目录（或用户级别的 skills 目录），会被自动识别。
- **Codex 或其他支持 Skill 机制的工具**：按该工具自己的说明把这个文件夹接入。
- **想直接在 Obsidian 里用**：需要一个能把 Obsidian 和 AI 工具连起来的社区插件——在 Obsidian 的"第三方插件"市场里搜索连接 Claude 的插件，安装、配置好 API access 之后，就能在写文稿时直接调用。

以上每个工具的具体菜单位置都可能随版本变化，装的时候找不到对应入口，去该工具当前的官方文档确认最新步骤。

### 第三步：开始用

直接用自然语言说你要写什么，比如"帮我把这个项目写成一篇小红书笔记"；也可以直接点名"用 miki-writer 帮我写……"，确保触发的是这个 Skill，而不是模型自己临场发挥。

## 它不会做的事

- 不自动发布、群发、登录平台后台或操作账号密码——这些动作永远需要你在对话里单独明确授权。
- 不编造经历、数据、评论或引语；许可证以仓库实际文件为准。
- 不写医疗/法律/理财担保性建议，不碰政治敏感、仇恨对立、骚扰动员内容。
- 材料不够时不会替你编一套完整立场，会先问你。

## 关于隐私和可移植性

会去读 Obsidian Vault 里已经整理好的素材来找背景信息，但**具体文件夹路径不是写死的**——`SKILL.md` 里出现的路径、文件名，都是使用者自己的个人配置。分享给别人时，对方按自己的 Vault 结构调整对应路径即可，不会暴露原使用者的笔记内容或目录组织方式。`references/ip-signature.md`（署名话术、避免词清单）和 `references/author-voice.md`（文风记忆）里的内容是原使用者自己的，拿去用时换成你自己的说法即可。
